# 产品简介

> doc_id: DOC01 · 产品：智答云 · 知识库版本：2026-Q3 · 生效：2026-07-01

## 适用范围

说明智答云是什么、解决什么问题、面向谁、有哪些客户端与能力边界。不涉及具体标价明细（见 DOC02）与实时账号数据。

## 规则正文

### 1.1 产品定位

智答云是一款面向团队的 **AI 知识管理与智能问答 SaaS**。客户可将制度、产品说明、项目文档等上传至工作区，构建私有知识库，并在网页端、桌面端通过对话完成检索问答；同时提供开放 API，供业务系统嵌入问答与检索能力。

核心价值：

1. **知识集中**：减少「政策在群里、制度在网盘、口径不一致」；
2. **可控问答**：回答可追溯到知识片段，降低纯模型编造；
3. **团队协作**：按角色管理成员与外部协作者，控制可见范围；
4. **可集成**：API / OCR / 分享链接等按套餐开放。

### 1.2 目标客户

1. **个人与微团队**：试用或基础版，验证知识库与问答效果；
2. **成长型小团队**：基础版或专业版，需要多知识库、API 与协作；
3. **中大型企业**：企业版，需要 SSO、专属支持、可选私有化与合同级 SLA。

### 1.3 主要能力清单

| 能力 | 说明 |
|------|------|
| 文档上传与解析 | 支持常见办公与文本格式（具体以产品界面当期支持列表为准） |
| 知识库管理 | 多知识库、文档上限依套餐；支持标签（专业版起增强） |
| 智能检索问答 | 按工作区知识回答；额度见 DOC03 |
| 团队协作 | 所有者 / 管理员 / 成员；外部协作者见 DOC04 |
| 开放 API | 基础版起按月额度；超额规则见 DOC03 |
| OCR | 基础版起按页额度 |
| 外部分享链接 | 基础版起；企业版可配密码与有效期 |
| SSO / 审计增强等 | 主要为专业版部分能力 + 企业版合同项 |

### 1.4 客户端与访问方式

1. **网页端**：默认主入口，含工作区、成员、计费、工单入口；
2. **桌面端**：与网页端账号体系打通，适合常驻使用；
3. **开放 API**：使用密钥调用；密钥保管责任在客户侧，泄露需立即重置。

### 1.5 与「智能客服助手」演示的关系

本仓库中的智能客服 Agent 演示，使用本知识库回答**智答云产品政策**；同时通过工具查询演示用订单/工单/额度，二者通道分离：

- 政策、规则、口径 → 本知识库（RAG）；
- 「我的订单现在什么状态」→ 业务查询工具，不以本文编造。

### 1.6 典型使用场景

1. **制度问答**：人事/行政把考勤、报销、差旅制度入库，员工用对话查询，减少重复答疑。
2. **产品与售前**：把产品白皮书、功能清单、竞品对比（对内）入库，售前快速定位口径。
3. **项目交付知识**：实施纪要、接口说明、FAQ 沉淀到项目知识库，降低人员流动带来的断层。
4. **业务系统嵌入**：通过 API 在工单系统、IM 机器人中回答「基于企业知识」的问题，额度计入 API 或 AI 额度（以调用方式与套餐说明为准，详见 DOC03）。

### 1.7 工作区与知识库概念

1. **工作区**：计费与成员管理的基本单位，通常对应一个团队或公司主体。
2. **知识库**：工作区内的文档集合；一个工作区可有多个知识库，数量受套餐限制（DOC02）。
3. **文档**：入库的最小内容单元；删除进入回收站规则见 DOC07。
4. 用户混淆「账号」与「工作区」时：一个账号可加入多个工作区，但计费与套餐以工作区订阅为准。

### 1.8 安全与隐私（对外口径摘要）

1. 客户上传内容归属与使用以用户协议及企业合同为准；客服不得承诺「我们绝对不会用于训练公有模型」之外、合同未写明的条款——涉及训练与数据使用须引导查阅当期《用户协议》或企业 DPA。
2. 外部分享链接具备泄露风险，应提醒客户设置必要权限与有效期（企业版可配密码与有效期，DOC08）。
3. API 密钥等同管理员凭证，泄露后应立即重置；平台侧配合审计以企业版能力与合同为准。

## 例外与边界

1. 智答云**不是**通用搜索引擎，默认只依据客户工作区内知识与平台政策库作答；
2. 医疗、法律等强监管领域的最终意见，平台不替代持证专业人士结论；
3. 模型供应商变更可能导致回答风格变化，不改变本政策文档中的商业规则；
4. 本简介不回答「我的工作区还剩多少次调用」——须查用量中心或账号工具。

## 客服话术要点

- 「智答云帮团队把文档建成可问的知识库，并按套餐提供问答次数、API 和协作能力。」
- 用户问「和 ChatGPT 有什么区别」：强调**基于客户自有知识、可权限管控、可追溯片段**，避免贬低竞品。
- 用户问「能代替我们的客服系统吗」：可作知识辅助，**工单流转、CRM、人工业绩**仍需客户自有系统；本库 DOC09 只说明智答云自身支持渠道。

## 禁止承诺

- 禁止承诺「100% 不幻觉」「一定通过等保某级」——安全合规以合同与当期认证材料为准；
- 禁止承诺具体上线日期的未发布功能；
- 禁止承诺「接入后一定减少一半人工」等无依据效果数字。
