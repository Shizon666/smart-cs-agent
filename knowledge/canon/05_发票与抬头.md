# 发票与抬头

> doc_id: DOC05 · 产品：智答云 · 知识库版本：2026-Q3 · 生效：2026-07-01

## 适用范围

中国区订阅的电子普通发票与增值税专用发票规则、开票时间、金额口径、抬头错误处理。退款与专票红字流程交叉见 DOC06。

## 规则正文

### 5.1 发票类型

1. 平台支持：**电子普通发票**、**增值税专用发票（专票）**。
2. 默认开票内容：**信息技术服务费**。
3. 特殊开票内容须在**付款前**联系销售确认是否可开，付款后无法保证变更成功。

### 5.2 开票时间与周期

1. **按月订阅**：支付成功后即可申请开票。
2. 同一自然月内若发生退款，**退款对应部分不能重复开票**。
3. **企业年付**：一般在款项到账并完成合同归档后统一开票。
4. 开具时效：资料齐全时，电子票通常在申请后 **1～3 个工作日**内开具（高峰期可能延长，以工单反馈为准）。

### 5.3 发票金额

1. 默认按**实际支付金额**开具，**不含已退还部分**。
2. **优惠券抵扣金额不开票**，只对用户实付部分开票。

### 5.4 专票资料

申请专票须维护完整开票信息，至少包括：公司名称、纳税人识别号、地址电话、开户行及账号等（以开票页必填项为准）。信息不全将驳回申请。

### 5.5 发票抬头错误如何处理

1. **尚未开具**：用户可在开票申请页自行修改抬头与税号后重新提交。
2. **已开具电子普票且尚未用于报销入账**：可提交工单申请作废/红冲后重开，须提供正确抬头；是否允许重开以财务审核为准，同一订单原则上限制次数，防止频繁变更。
3. **已开具专票**：必须走**红字发票信息确认**流程后，再重开正确专票；若同时涉及退款，**必须先完成红字流程再退款**（DOC06）。
4. 因用户自身填错导致的多次重开，平台可能要求提供加盖公章的说明；客服不得口头承诺「无限次免费重开」。

### 5.6 规则速查表

| 项 | 口径 |
|----|------|
| 是否支持专票 | 支持 |
| 默认内容 | 信息技术服务费 |
| 月付开票时机 | 支付成功后可申请 |
| 券抵扣 | 不开票 |
| 专票后退款 | 先红字，后退款 |

### 5.7 开票信息变更与企业更名

1. 公司更名：提供工商变更证明与新开票资料，经财务审核后用于**后续**订单；已开旧票是否换开按税务与财务审核，不保证所有历史票都能换开。
2. 合并开票：同一付款主体多笔月付是否合并一张，以财务当期能力为准；不能承诺「跨年合并」。

### 5.8 常见误解

1. 「付了钱就自动开票」——需用户发起申请（企业年付可能由销售统一申请）。
2. 「退款了发票还能继续报销同一笔」——退款对应部分不可重复作为有效应税凭证使用；专票须红字。
3. 「个人抬头也能开专票」——通常不符合专票条件，应开普票。

### 5.9 申请开票检查清单

1. 确认订单已支付成功且未全额退款；
2. 选择普票或专票；专票资料：名称、税号、地址电话、开户行账号；
3. 开票内容默认「信息技术服务费」，特殊内容须付款前已确认；
4. 核对金额=实付（不含券）；
5. 提交后保存申请单号，便于工单追踪。

## 例外与边界

- 个人用户是否具备专票资质以税务与平台审核为准；不符合专票条件的应开普票。
- 第三方代付、加盟商代开等复杂主体，升级人工财务处理。
- 电子票下载链接过期可工单重发，不视为重新开具金额。

## 客服话术要点

- 先问：普票还是专票、是否已开出、是否已报销。
- 退款单提醒：有专票别直接说「马上退」，先讲红字。
- 资料不全时列出缺项清单，避免来回多轮。

## 禁止承诺

- 禁止承诺法定以外的开票内容（如随意改成「软件销售」等未确认类目）；
- 禁止承诺「今天一定开出」若资料不齐；
- 禁止承诺「一定免税」或具体税率解释（税率以发票实际开具为准，客服不做法务税务鉴定）。
