# 工单与服务渠道说明

> doc_id: DOC09 · 产品：智答云 · 知识库版本：2026-Q3 · 生效：2026-07-01

## 适用范围

各套餐人工支持渠道、标准工单响应口径、紧急问题定义、以及工单与「订单查询工具」的分工。不提供某一工单号的实时进度（须查业务系统）。

## 规则正文

### 9.1 各套餐服务渠道

| 套餐 | 渠道 |
|------|------|
| 试用版 | 仅工单 |
| 基础版 | 工单 + 工作日在线客服 |
| 专业版 | 工单 + 工作日在线客服 + 紧急问题电话 |
| 企业版 | 上述能力按合同；另有 CSM 与专属群（DOC08） |

工作日：默认北京时间周一至周五 9:00～18:00（法定节假日以公告为准）。

### 9.2 标准工单响应口径（非企业合同 SLA）

适用于试用/基础/专业及未单列 SLA 的场景：

| 级别 | 定义（摘要） | 首次响应目标 |
|------|--------------|--------------|
| 普通 | 咨询、配置、发票、一般缺陷 | **1 个工作日内** |
| 紧急 | 生产环境服务不可用、无法登录且影响多数成员、或专业版电话升级的同类事件 | **4 小时内**（优先工作时间处理；跨夜事件进入工作时间后起算加急，具体以工单系统戳记为准） |

企业版若合同含 SLA，**以合同为准**，本表仅作无 SLA 时的参考。

### 9.3 如何提交与升级

1. 产品内「帮助与工单」提交；尽量提供工作区 ID、时间点、截图、订单号。
2. 退款/专票/注销等敏感类：工单类型选对应分类，避免丢到「产品建议」队列。
3. 专业版紧急电话：仅用于紧急定义内事件；滥用可能转为普通工单。

### 9.4 工单进度 vs 知识库 vs 订单工具

| 用户问题 | 正确通道 |
|----------|----------|
| 「退款规则是什么」 | 知识库 DOC06 |
| 「我的工单 T001 处理到哪了」 | **工单查询工具/后台**，禁止编造 |
| 「订单 ORD002 状态」 | **订单查询工具** |
| 「能不能保证 10 分钟响应」 | 查是否企业 SLA 合同；否则按本表，不承诺更高 |

### 9.5 无依据定制承诺的处理

当用户要求本库未写明的权益（如「多留一年数据」「破例全额退」「免费加人」）：

1. 明确告知：**当前标准知识库无此承诺**；
2. 引导：**升级人工**或请客户经理出具书面审批；
3. 智能客服**不得**口头答应后指望事后补手续。

### 9.6 工单填写质量要求（降低驳回）

1. 标题含产品模块与现象；正文含复现步骤、发生时间、影响范围（几人/是否生产）。
2. 附件：截图、错误码、订单号/工单号、工作区 ID。
3. 敏感信息（身份证、完整银行卡）不要发到工单公开字段，按财务指引加密通道提供。

### 9.7 升级路径

1. 普通咨询 → 在线客服/工单；
2. 专业版紧急 → 电话 + 工单双开；
3. 企业版 → 专属群 @约定值班，并保留工单号便于追溯；
4. 政策争议、退款特批、合同 SLA → 人工主管/CSM/法务，不在智能客服闭环内承诺结果。

### 9.8 常见误解

1. 「提交工单就等于已加急」——加急要符合紧急定义或企业 SLA。
2. 「智能客服说的响应时间可以当合同」——无合同 SLA 时仅为目标口径。
3. 「查 ORD/T 进度靠背政策」——必须用业务查询工具。

### 9.9 渠道选择速查

| 诉求 | 优先渠道 |
|------|----------|
| 规则咨询（退款/额度/发票政策） | 智能客服知识库 + 必要时工单 |
| 实时订单/工单进度 | 业务查询工具（要单号） |
| 账号打不开/大面积故障 | 紧急工单；专业版可电话；企业版专属群 |
| 特批退款/特批留数 | 人工主管书面审批，智能客服不承诺 |
| 企业 SLA 赔偿 | 合同 + CSM/法务，不用本库数字替代 |

## 例外与边界

- 舆情、媒体危机等非标准技术工单走企业公关与 CSM，不在普通队列承诺时效内。
- 第三方支付渠道故障导致的到账延迟，平台协助排查但不承担渠道侧 SLA。
- 法定节假日响应可能延长，以公告为准。

## 客服话术要点

- 先分级：紧急还是普通，再给时效预期。
- 查进度：要工单号，走工具。
- 特批类：明确「库内无承诺 → 转人工书面审批」。

## 禁止承诺

- 禁止承诺短于本表且无合同依据的响应时间；
- 禁止假装已经「派单成功」而无系统记录；
- 禁止承诺库外权益（多留数据、破例全额退、免费加人等）。
