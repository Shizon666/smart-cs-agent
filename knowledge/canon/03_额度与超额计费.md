# 额度与超额计费

> doc_id: DOC03 · 产品：智答云 · 知识库版本：2026-Q3 · 生效：2026-07-01

## 适用范围

说明 AI 问答额度、API 调用额度、OCR 页数额度的统计周期、是否结转、超额后是否停用及阶梯价格。企业版若合同另有约定，以合同为准。

## 规则正文

### 3.1 三类额度互相独立

1. **AI 问答额度**、**API 调用额度**、**OCR 页数额度**分开统计、分开耗尽，**互不挪用**。
2. 用户问「额度超了还能用吗」时，必须先确认是哪一类额度。

### 3.2 AI 问答额度

1. 按**自然月**统计，每月 **1 日 00:00** 自动重置；**未使用额度不结转到下月**。
2. 套餐内含（标准）：试用 200 / 基础 5000 / 专业 30000（次）；企业版按合同。
3. **超额停用规则**：AI 问答额度用尽后，系统**停止继续提供问答服务**，直到：
   - 下月额度重置；或
   - 用户主动升级到更高套餐并完成生效。
4. AI 额度用尽**不会**自动按次扣费续用（与 API 不同）。

### 3.3 API 调用额度

1. 基础版每月含 **10000** 次；专业版每月含 **80000** 次；试用版不支持 API。
2. **超额后不会立刻停用**，继续提供服务，并在账单中统计超额费用。
3. 当月超出套餐内含部分的「超额调用」按阶梯计费（只计超出部分，不是总调用量）：

| 超额调用量（次） | 单价 |
|------------------|------|
| 0 ～ 10000 | 8 元 / 每 1000 次 |
| 10001 ～ 50000 | 6 元 / 每 1000 次 |
| 50001 次以上 | 4 元 / 每 1000 次 |

4. **计费示例**：
   - 基础版当月共调用 18000 次：内含 10000，超额 8000 → 按第一档计费。
   - 专业版当月共调用 95000 次：内含 80000，超额 15000 → 其中 10000 按第一档，5000 按第二档。

### 3.4 OCR 页数额度

1. 同样按自然月统计，每月重置，未用完不累计。
2. 试用不支持；基础 **200** 页/月；专业 **2000** 页/月；企业按合同。
3. **OCR 超额后**：图片解析功能**暂停**；**普通文本问答不受影响**（仍受 AI 额度约束）。

### 3.5 超额后的恢复与扣费

| 类型 | 超额表现 | 如何恢复 | 是否自动扣费续用 |
|------|----------|----------|------------------|
| AI 问答 | 停止问答 | 下月重置或升级套餐 | 否 |
| API | 不停用 | 持续可用；账单结算超额 | 是（阶梯计费） |
| OCR | 暂停解析 | 下月重置或升级 | 否（标准订阅无 OCR 按次自动加购；企业另约除外） |

### 3.6 查询「我还剩多少额度」

本政策文档**不包含**某一用户当前剩余次数。客服/助手应引导用户提供账号 ID（如演示环境 U001）走**账号额度查询工具**，或指引控制台「用量中心」。

### 3.7 阶梯计费再说明（客服易算错点）

1. 分段按**超额部分**累计，不是「一超全部打到最高档」。
2. 不足 1000 次的计费最小展示单位以账单为准；对外解释可说「按每千次单价折算，具体以账单行项目为准」。
3. 用户用「总调用量 × 8 元」估算通常**偏高或偏低都可能错**，应引导看账单「超额」行。

### 3.8 与退款的关系

1. 退款资格看 **AI 问答使用量占比**（DOC06），不是 API 超额多少。
2. 即使 API 产生超额费用，仍可能因 AI 使用量过高而无法退订阅款；反之 AI 很少用但 API 很多，仍可能满足 AI 维度的退款比例——两套逻辑不要混谈。

### 3.9 常见误解

1. 「超额了系统会自动升级套餐」——不会，需用户主动升级。
2. 「OCR 超了问答也不能用」——不对，仅暂停图片解析。
3. 「企业版一定和专业版一样按自然月重置」——不一定，以合同为准。

### 3.10 情景答复模板（可检索）

**情景 A：「额度超了还能用吗」**  
反问哪类额度。API：一般还能用，账单阶梯计费。AI：用完停止问答，下月重置或升级。OCR：暂停解析，文本问答仍可用（仍受 AI 额度限制）。依据 DOC03 §3.1～3.5。

**情景 B：基础版本月 API 打到 18000，问要交多少**  
内含 10000，超额 8000，落在第一档（8 元/千次）；精确金额以账单为准，解释分段逻辑避免总调用量×单价。依据 DOC03 §3.3。

**情景 C：AI 停了，要求「先透支下月」**  
标准订阅不支持 AI 透支自动扣费续用；选项是升级套餐或等自然月重置。依据 DOC03 §3.2、§3.5。

**情景 D：要查 U001 剩余额度**  
政策库无实时余额；走账号额度查询工具或用量中心。依据 DOC03 §3.6、DOC00。

## 例外与边界

1. 企业版可能按合同采用非自然月重置或包年池，不得强行套用上表。
2. 故障补偿赠送额度以公告或工单结论为准，本库不预设赠送比例。
3. 第三方模型供应商宕机导致的失败调用是否计费，以产品状态页与合同为准；争议升级工单。

## 客服话术要点

- 高频澄清：「API 超了一般还能调，只是要钱；AI 次数用完会停问，这是两套规则。」
- 给阶梯价时提醒「按超出部分分段」，避免用户按总量乘单价。
- 用户要「现在剩余多少」：要账号 ID，走查询工具或让用户打开用量中心，不要猜。

## 禁止承诺

- 禁止承诺「帮你免掉已产生的超额费用」；
- 禁止承诺「AI 用完还能先用着下月再算」；
- 禁止口头报一个与账单不符的剩余次数。
