# 企业版支持与 SLA

> doc_id: DOC08 · 产品：智答云 · 知识库版本：2026-Q3 · 生效：2026-07-01

## 适用范围

企业版专属支持、CSM、服务群、SLA 与私有化/定制能力边界。标准 SaaS 基础/专业版不适用本篇全部条款。

## 规则正文

### 8.1 专属支持是否包含

1. 企业版**默认提供**：专属客户成功经理（**CSM**）、专属服务群。
2. **SLA**：仅当合同**明确包含 SLA 条款**时，按合同响应与恢复指标执行。
3. **知识库政策能否代替合同 SLA 数字？** **不能。** 智能客服与本库只提供默认口径；**具体分钟数、赔偿条款以签署合同为准**。若用户坚持要「合同里的数字」，应升级人工并调阅合同，禁止用本库杜撰赔偿比例。

### 8.2 未签署 SLA 时的默认响应口径

适用于已开通企业版但合同未附 SLA 的客户：

| 类型 | 默认首次响应 |
|------|----------------|
| 重大故障（服务大面积不可用） | **2 小时内** |
| 普通问题 | **1 个工作日内** |

该默认口径**不是**赔偿承诺，仅作支持响应目标。

### 8.3 私有化部署

1. 企业版**可选**私有化，**不是**标准内容，**不是**「企业版一定支持且已包含」。
2. 私有化通常含实施、部署、验收、维护等阶段，费用与范围**合同约定**。
3. 答复「是否一定支持私有化」：**可以选配，需单独签约确认；未签约则不能承诺交付。**

### 8.4 其他定制能力

SSO、专属算力隔离、审计增强、定制审批流、定制数据保留等：

1. 企业版**支持作为能力项商务谈判**；
2. **是否免费包含**取决于商务方案，**不是**所有企业版订单自动包含全部定制。

### 8.5 与标准版支持的差异（摘要）

| 能力 | 基础/专业 | 企业版 |
|------|-----------|--------|
| CSM | 无 | 默认有 |
| 专属群 | 无 | 默认有 |
| SLA | 无合同级 SLA | 合同可选 |
| 私有化 | 无 | 可选签约 |
| SSO | 非标准（专业无完整企业 SSO 时以产品为准） | 支持（合同） |

### 8.6 售前与客服分工

1. **客服**：解释本库默认口径、引导查合同、登记需求转 CSM/销售。
2. **销售/CSM**：报价、SLA 谈判、私有化范围、定制清单与排期。
3. 智能客服遇到「给我个最低价」「签了就上私有化」：收集场景后转人工，不报价、不承诺排期。

### 8.7 常见误解

1. 「所有企业版都有赔偿型 SLA」——只有合同写了才有。
2. 「CSM 就是 7×24 坐席」——CSM 是客户成功与协调角色，紧急技术响应仍走约定支持通道与工单/群。
3. 「标准版付费升级就能瞬间变企业版含私有化」——企业版与私有化都是商务流程，不是纯自助开关。

### 8.8 企业版沟通检查清单

1. 是否已签约企业版主合同？
2. 合同是否含 SLA 附件？若无，仅能引用默认响应目标，不能谈赔偿数字。
3. 是否单独签署私有化/定制附表？未签则不能承诺私有化交付。
4. CSM 与专属群是否已开通？未开通转销售。
5. 用户要合同级分钟数 → 升级人工调阅合同，禁止用本库杜撰。

## 例外与边界

- 集团多法人、多工作区打通属实施方案，本库不展开报价。
- 私有化现场网络与客户安全审批延误不计入平台单方延误责任时，以合同为准。
- 试用/基础/专业用户询问企业能力时，可介绍差异，但不得假装其已享有 CSM。

## 客服话术要点

- 「有没有 CSM」：企业版默认有；基础/专业没有。
- 「SLA 赔多少」：必须查合同，本库只给未签 SLA 时的默认响应目标。
- 私有化：三句话——可选、需单签、未签不能承诺。

## 禁止承诺

- 禁止承诺未签约的私有化上线时间；
- 禁止用本库数字替代合同赔偿条款；
- 禁止承诺「所有企业版都含全部定制」；
- 禁止承诺具体折扣率或「一定低于竞品」。
