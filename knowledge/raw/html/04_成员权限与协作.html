成员权限与协作


doc_id: DOC04 · 产品：智答云 · 知识库版本：2026-Q3 · 生效：2026-07-01


适用范围


正式成员计数、角色权限、外部协作者、权限生效时间。套餐人数上限数字与 DOC02 一致。


规则正文


4.1 正式成员计数口径


1. 成员数按已激活成员计算；已邀请但尚未激活的成员暂不计入套餐人数上限。

2. 成员被停用后：停用当日仍计入成员数，自次日起不再计入。

3. 各套餐正式成员上限：试用 1 / 基础 10 / 专业 50 / 企业按合同。


4.2 角色类型


系统默认三种角色：


| 角色 | 权限要点 |

|------|----------|

| 所有者 | 计费、删除工作区、导出全部数据、安全策略等最高权限 |

| 管理员 | 可管理成员、知识库、标签和大部分配置；不能删除工作区；不能修改计费主体 |

| 普通成员 | 在授权范围内上传文档、提问、查看知识库；不能管理计费与安全策略 |


4.3 管理员与审计日志


1. 专业版及以上支持审计日志导出（见 DOC02）。

2. 管理员能否删除审计日志？

- 不能删除已落库的审计日志（含导出副本在平台侧的保留策略内记录）。

- 管理员可管理知识库内容与成员，但审计日志用于安全合规，无「清空审计」权限。

- 所有者亦不得在控制台一键销毁合规审计；特殊删除需求须法务流程且企业合同另有约定时由人工处理。

3. 普通成员不能查看全局审计。


4.4 外部协作者


1. 基础版及以上支持外部协作者；试用版不支持。

2. 外部协作者不占用正式成员名额，但：

- 只能访问被授权的指定知识库；

- 不能访问团队设置、计费页面和全局日志。

3. 数量上限：基础版 20；专业版 100；企业版按合同。


4.5 权限生效时间


1. 控制台内角色调整通常实时生效。

2. 若涉及 SSO 组织架构同步，可能存在最长 15 分钟延迟。

3. 企业版若启用自定义权限映射，以映射落地结果为准。


4.6 所有者变更与交接


1. 工作区必须保持至少一名所有者；转让所有者后，原所有者可降为管理员或成员。

2. 删除工作区仅所有者可发起（DOC07）；管理员不能「曲线删库」。

3. 账号注销前若仍为唯一所有者，须先转让或删除工作区（DOC07 §7.6）。


4.7 权限相关常见场景


1. 成员看不到某知识库：先查是否未授权、是否仅为外部协作者且未加到该库、是否 SSO 延迟未同步。

2. 管理员改不了计费：符合设计；计费主体与套餐变更属所有者权限。

3. 审计导出失败：确认是否专业版/企业合同含审计能力；基础版无审计导出（DOC02）。


4.8 安全建议口径（非惩罚性）


1. 最小化授权：外部协作者仅开必要知识库。

2. 离职当天停用账号，次日起不再计入名额，同时收回 API 密钥与分享链接。

3. 不要在工单里要求客服「远程直接改角色」而不经所有者确认——涉及越权。


4.9 角色对照速查（可检索）


| 动作 | 所有者 | 管理员 | 普通成员 | 外部协作者 |

|------|--------|--------|----------|------------|

| 上传授权库文档 | 是 | 是 | 视授权 | 视授权 |

| 邀请正式成员 | 是 | 是 | 否 | 否 |

| 修改计费/套餐 | 是 | 否 | 否 | 否 |

| 删除工作区 | 是 | 否 | 否 | 否 |

| 导出审计日志 | 专业版+有权限角色 | 专业版管理员通常可 | 否 | 否 |

| 清空审计日志 | 否 | 否 | 否 | 否 |

| 访问计费页 | 是 | 否 | 否 | 否 |


说明：导出审计不等于删除审计；「清空审计」全角色默认不可（见 §4.3）。


例外与边界


- 「访客只读链接」属于外部分享能力，不等于外部协作者账号；分享链接规则见产品界面与企业版密码/有效期配置（DOC08）。

- 渠道子账号、集团多工作区映射以企业实施方案为准。

- 自定义角色若企业合同另行配置，以落地映射为准，本库仅描述默认三角色。


客服话术要点


- 「外部协作不占正式名额，但有数量上限，而且只能进你授权的库。」

- 用户觉得「邀请了怎么还是人数满了」：先查是否已激活、是否把协作者当成正式成员邀请。

- 审计删除类诉求：明确拒绝并解释合规原因，可提供导出留存建议。


禁止承诺


- 禁止承诺「管理员可以清掉审计痕迹」；

- 禁止承诺突破套餐人数的「先加后补钱」且无账单依据；

- 禁止在未验证身份时协助变更所有者。
