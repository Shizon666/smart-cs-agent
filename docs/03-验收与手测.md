## L2 手测步骤

1. Milvus 已启动 → 入库成功  
2. 问退款/超额类 FAQ → 有检索依据 + 合理回答  
3. 问「北京今天天气」→ 走天气 Tool，有数值  
4. （MCP 就绪后）问搜新闻并情感分析 → 调用 MCP 工具  
5. 停掉 MCP 再问 FAQ/天气 → 仍可用
