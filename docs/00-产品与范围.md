# 00 — 产品与范围

## 一句话

面向客服/顾问场景的 **智能客服 Agent**：私有知识库问答 + 实时工具 + 可插拔外部能力（MCP）。

## 一期必做（单 Agent）

| 能力 | 说明 |
|------|------|
| RAG 问答 | 套餐/退款/发票等，基于知识库检索再回答 |
| 天气 | 本地 Tool，Open-Meteo |
| 新闻舆情邮件 | MCP Server 提供工具，由同一 Agent 调度 |

## 一期不做

- 多 Agent / Supervisor
- 前端 UI、用户登录鉴权
- Rerank、评测平台、微服务拆分
- 绑定「尚硅谷 / atguigu」对外品牌（仅历史教程参考）

## 演示用例（完成定义）

1. FAQ：退款被拒 / API 超额 → 能引用知识库口径  
2. 天气：问北京天气 → 真实气温等  
3. MCP：搜新闻并做情感分析（发邮件单独确认再测）
